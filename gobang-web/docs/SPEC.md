# Gobang Web - 技术规格说明书

## 1. 游戏规则

### 1.1 基本规则
- 棋盘: 15x15
- 棋子: 黑方先手，双方轮流落子
- 胜利条件: 任意方向（水平/垂直/对角）连续五子

### 1.2 游戏流程
1. 游戏开始，黑方先手
2. 玩家点击空位落子
3. 系统判断是否有五子连珠
4. 若有，则判定胜负；若无，则换对方落子
5. 棋盘满则判为平局

## 3. 数据结构

### 3.1 棋盘状态
```typescript
type Player = 'black' | 'white';
type Cell = Player | null;
type Board = Cell[][]; // 15x15
```

### 3.2 游戏状态
```typescript
interface GameState {
  board: Board;
  currentPlayer: Player;
  gameMode: 'pvp' | 'ai';
  difficulty: 'easy' | 'medium' | 'hard';
  status: 'playing' | 'ended';
  winner: Player | 'draw' | null;
  moveHistory: [number, number][];
  lastMove: [number, number] | null;
}
```

## 4. AI 算法设计

### 4.1 算法选择
- **Minimax** + **Alpha-Beta Pruning** + **评估函数**

### 4.2 评估函数
- 连子评分:
  - 活四: 100000
  - 冲四: 10000
  - 活三: 10000
  - 眠三: 1000
  - 活二: 1000
  - 眠二: 100
- 位置权重: 中心位置加分

### 4.3 搜索深度
| 难度 | 深度 |
|------|------|
| easy | 2 |
| medium | 4 |
| hard | 6 |

## 6. 技术实现要点

### 6.1 胜负判定算法
从最后落子位置，向 4 个方向（水平/垂直/两个对角）搜索，统计连续相同棋子数。

### 6.2 AI 落子时机
使用 `setTimeout` 延迟 500ms 落子，模拟"思考"效果。

### 6.3 状态管理
使用 React Context + useReducer 管理全局游戏状态，便于悔棋和历史回放。
