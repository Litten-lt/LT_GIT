# Gobang Web - 游戏平台

## 1. 项目背景
- **市场需求**: 休闲棋类游戏需求稳定，规则简单易懂，适合各年龄段
- **用户痛点**: 现有棋类游戏多为单机版或需下载安装，缺乏可直接在浏览器游玩的体验
- **目标**: 打造一款支持多种棋类游戏的网页平台

## 2. 系统/方案概述
- **前端**: React 18 + TypeScript + Vite + Tailwind CSS + Vitest
- **后端**: Node.js + Socket.IO (在线对战服务器)
- **架构模式**: 页面路由 + useReducer 状态管理
- **游戏模式**: 本地双人 / AI对战 / 在线对战
- **部署方式**: 单页应用 + Socket.IO 服务器

## 4. 方案设计
- **大厅**: 深色科技风格卡片网格布局
- **游戏**: 独立组件封装（GobangGame）
- **AI**: Minimax + Alpha-Beta + 评分函数
- **在线**: Socket.IO 实时通信 + 内存房间管理
- **UI**: 科技蓝/紫色渐变主题

## 5. 关键实现
1. **游戏大厅**: 游戏卡片网格，支持游戏选择和状态显示
2. **游戏隔离**: 每款游戏独立组件，通过游戏ID路由
3. **扩展接口**: GameInfo 类型定义，预留游戏注册机制

## 6. 测试与验证
- ✅ 单元测试: AI评估函数、胜负判定逻辑、Reducer状态管理
- ✅ 集成测试: 完整游戏流程（开局→落子→判定→结束）
- ✅ 手动测试: 本地/AI/在线各模式对战


```bash
cd gobang-web/server
```
